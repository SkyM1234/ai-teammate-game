# 游戏背景音乐

当前只启用三首程序合成音乐，没有使用外部录音或第三方音乐采样：

| 文件 | 音乐 | 播放方式 |
| --- | --- | --- |
| bgm-exploration.wav | 探索 · 静默空间站 | 90 秒循环 |
| rescue-success.wav | 结局 · 救援成功 | 4.3 秒，播放一次 |
| mission-failure.wav | 结局 · 生命信号消失 | 3.4 秒，播放一次 |

探索曲为 64 BPM、D 小调、24 小节，六个乐句以附加音与悬挂和声营造未完全解决的空间感。去掉持续低音、低频起伏和长音铺底，只保留中央 C 以上的短和声、带留白的钟声音型、立体声延迟，以及后半段的呼应。旋律起音更柔和，乐句之间保留空隙。跨边界的音符与混响按周期渲染；Web Audio 解码后按采样循环。

结局保留原样音的短旋律与时长。全部文件为 44.1 kHz、16-bit、立体声 WAV；探索曲峰值约 -9.9 dBFS，两首结局曲峰值约 -6 dBFS；游戏默认播放音量 35%。

首次点击或键盘操作后开始播放；左上角音符按钮开关音乐，并在本机记住选择。切到后台时暂停，返回后续播。结局随当前对局状态切换，普通界面刷新不重新播放。查看行动回放时音乐停止，避免拖动回放重复触发结局。

重新生成需要 Python 3 和 NumPy：在游戏目录运行 `python scripts/generate-music.py`，再运行 `npm run build`。日常启动和构建直接使用已有 WAV，不需要 Python。脚本检查峰值及循环接缝与相邻采样的变化幅度；听觉品质仍需实际试听评估。
