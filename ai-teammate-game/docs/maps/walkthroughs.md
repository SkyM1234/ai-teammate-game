# 地图通关说明

[返回地图索引](README.md)。坐标从 0 开始，格式为 (x,y)。以下是作者预设的合法路线；游戏内“规则通关”使用各地图的主路线，备用路线用于验证其他策略。具体每一步以地图 JSON 的 `verification` 为准，资源结算见 [route-ledgers.json](route-ledgers.json)。

## station-01 · 第七站 · 事故舱

### 共同准备

1. 从机器人起点 (2,9) 前往 (2,8)，取得 (3,8) 的维修材料 `s-01`。
2. 返回 (2,9)，修补伤员供氧管；前往 (1,9) 抱起伤员。
3. 经 (4,9)、(4,3) 到达 (2,3)，取得 (2,2) 的第二份维修材料 `s-02`。

### 主路线 main：上方电动门

1. 经 (4,3)、(4,2) 到达 (6,2)，操作 (6,1) 的开关 `sw-01` 通电。
2. 前往 (6,3)，开启 (7,3) 的电动门 `d-01`。
3. 返回 (6,2) 断电，再经 (6,3)、(7,3)、(8,3) 穿门，避免线路带电。
4. 沿右侧通道前往 (8,9)，修复 (9,9) 的气闸控制器 `a-01`。
5. 经 (8,1) 到达出口 (10,1)，执行撤离。

全程 58 TU，剩余氧气 53、电量 28。该路线提前搬运伤员，不需要额外电池或氧气；正常探索会增加消耗，可自行使用其他补给。

### 备用路线 lower：下方清障

取得第二份材料后经 (4,3)、(4,10) 前往 (6,10)，清理 (7,10) 的坍塌金属架 `o-01`；经 (8,10) 前往 (8,9) 修复气闸，再沿右侧通道到达 (8,1)、(10,1) 并撤离。

全程断电，56 TU，剩余氧气 55、电量 29。它减少开关往返，但需承担清障消耗。

## station-02 · 第八站 · 环形救援舱

### 共同准备

1. 在起点 (3,12) 取得 (4,12) 的维修材料 `s-01`，修补相邻伤员的供氧管。
2. 前往 (3,11)，取得 (4,11) 的气闸维修材料 `s-02`。
3. 返回 (3,12)，再到 (2,12) 抱起伤员。

### 主路线 main：设备间与电动门

1. 经 (3,12)、(3,11) 到达 (3,10)，取得 (4,10) 的氧气 `s-03` 并给搬运中的伤员补氧。
2. 沿 x=3 向北，在 (3,8) 开启 (3,7) 的手动门 `d-01`，继续前往 (3,3)。
3. 沿 y=3 到达 (6,3)，操作 (6,4) 的开关 `sw-01` 通电。
4. 返回 (5,3)，开启 (5,2) 的电池柜 `c-01`，取得并使用电池 `s-04`。
5. 返回 (6,3)，开启 (7,3) 的电动门 `d-02`，随后操作相邻开关断电。
6. 沿 y=3 穿门前往 (11,3)，修复 (12,3) 的控制器 `a-01`。
7. 经 (11,2)、(12,2)、(13,2) 前往出口 (13,1)，执行撤离。

全程 52 TU，剩余氧气 101、电量 77，补给后保留较多资源。

### 备用路线 lower：补给仓绕行

抱起伤员后经 (3,12)、(3,11) 到达 (6,11)，清理 (7,11) 的货架 `o-01`；沿 y=11 前往 (11,11)，向北到 (11,8) 开启 (11,7) 的手动门 `d-03`，继续到 (11,3) 修复控制器，最后经 (11,2)、(13,2)、(13,1) 撤离。

全程断电，不使用补氧或电池，44 TU，剩余氧气 69、电量 54。补给仓的其他物资仍可供探索和自行规划的路线使用。
