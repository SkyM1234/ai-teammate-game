# 地图资料

使用当前已有的实体与救援机制时，新增地图只需增加一个 `content/levels/*.json`。尺寸、布局、物资、资源、运行预算和规则通关路线均配置在同一文件中。

| 文件 | 内容 |
| --- | --- |
| [authoring.md](authoring.md) | 制作流程、JSON 字段、预算、存档与路线配置 |
| [template.json](template.json) | 已通过救援验证的 7×5 起步模板，不作为正式地图加载 |
| [walkthroughs.md](walkthroughs.md) | 各地图的通关步骤及路线差异 |
| [route-ledgers.json](route-ledgers.json) | `npm run verify:routes` 生成的全部地图逐动作资源账本 |
| [共享美术库](../art-library.md) | 公共模型、材质与地图主题复用 |

## 游戏内规则通关

新建所选地图，在“本地规则演示”模式下打开“救援目标”，点击“规则通关”；也可以发送“规则通关”“完成救援”或“一键救援”。按钮使用当前地图的 `verification.actions`，依照预算自动分段继续，直至救援完成或遇到无法继续的状态。不请求外部模型。

执行中可点击“停止行动”；若已执行动作仍与预设路线一致，点击“继续任务”即可接续。手动操作偏离路线时，程序会提示新建对局。真实模型模式隐藏该入口，并沿用正常任务理解与授权规则。

```powershell
npm run verify:levels
npm run verify:routes
```

布局或资源变更后，先更新同一 JSON 内的路线，重跑上述命令，并同步本表与通关说明。新地图重启服务后自动出现在列表中；已有存档使用各自保存的地图副本。
