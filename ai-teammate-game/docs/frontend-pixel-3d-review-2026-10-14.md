# 像素风 3D 前端改造

将原有地图改为 Three.js 正交相机下的斜俯视空间站。低分辨率渲染、最近邻放大、方块角色、金属墙体、硬阴影与有限状态色构成像素风画面。

整体界面参考工作区 `UI.png`：圆形中央观察窗、同心仪表环、左右控制区、浅色金属操作面板、深绿背景与黄色指示。保留 LAST OXYGEN 的救援目标和资源语义。

后续根据原图重新构建完整布局，取消三栏和固定表单：中央圆盘占画面高度约 88%，配合厚重分段环带、断开刻度弧线、倾斜图标按钮、黄色弧形操作带、身份卡和工业背景。在 UI 重排完成后，单独更新 `station-renderer.ts`，使 3D 场景的色彩与材质匹配新界面。

场景使用橄榄绿、灰白金属、荧光黄与暖琥珀色。程序生成铆钉地板和通风板像素纹理，添加分层底座、护栏与克制的警示涂装。重新制作履带机器人、担架伤员和全部可观察设备；灯光与材质使用统一色调，角色标签按文字宽度生成底板。几何零件按共享材质实例化，内部渲染尺寸为 CSS 尺寸的 75%，以保留像素边缘并改善细节。

板材纹理缩小时使用 mipmap 过滤，减少手机小视窗中的细纹混叠；放大时使用最近邻采样，保留像素纹理。

## 已实现

- 立体地板与墙体，R-07、伤员、物资、柜体、门、开关、危险和气闸控制器模型。
- 地图只接收 `PlayerView`，已确认对象和未知回波使用现有感知数据。
- OrbitControls 自由旋转、平移和缩放；鼠标左键拖动旋转、右键拖动平移、滚轮缩放，触屏单指旋转、双指缩放和平移。
- 保留旋转 90 度、缩放、复位、悬停和点击选格，使用地图原始坐标发送移动目标；拖动不误选，窗口变化保留相机视角。
- 游戏终端样式、分段资源条、目标进度、低氧预警、机器人头像与折叠运行记录。
- 八个功能面板按需展开：附近操作、物资管理、生命监测、救援目标、共享标记、行动记录、机器人通信与操作指南。
- 桌面侧边面板、手机底部面板，关闭/Escape/点击外部返回，关闭后恢复入口焦点；手机入口移至圆盘下方，提供触屏按钮与安全区域留白。
- 无 WebGL 2 时回退至平面地图，缩入圆形视窗以显示四角；移动动画遵循减少动态效果设置，隐藏页面停止动画。
- 单独前端构建命令 `npm run build`，启动依旧使用 `npm run dev`。

## 验证结果

- `npm run check` 与 `npm run build` 通过。
- `npm test`：71 项通过，0 项失败。
- `npm run verify:routes`：两条救援路线均成功，资源结果与既有记录一致。
- Chromium 浏览器检查：1920×1080、1440×900、1366×768、1024×768、390×844、360×740、320×568、844×390；未出现横向溢出或画布消失。
- 4 个相机方向下 28 次已知格子的精确点击验证通过，包括墙体、地面和出口。
- 新增相机交互检查通过：鼠标旋转/平移/滚轮、拖动不误选、拖动后点击、窗口变化保留视角、失焦取消、复位、真实 Chromium 单指/双指事件、触屏取消后轻触选格。
- 新布局下的八个面板、关闭与焦点恢复、选格、共享标记、按钮/键盘移动、资源同步、回放滑块、回到实时、模型设置、保存和存档列表、手机通信检查通过，浏览器运行错误为 0。
- 授权入口徽标、打开后定位授权按钮、拒绝请求及徽标清除，在 1440×900、390×844、320×568 下验证通过；请求和响应采用网络模拟，未提交实际授权动作。
- 成功和失败页面使用浏览器网络模拟的终局数据验证，终局提示显示正确且发送按钮禁用。
- 模拟不可用的 WebGL 2 后，平面地图正常显示且四个角落均可以点击选格。
- 正常页面没有浏览器运行错误。坐标验证用临时探针载入了第二份 Three.js，产生一次重复导入提示；探针位于忽略的 `output/` 内，不进入产品构建。

## 3D 场景更新验证

本次重新执行类型检查与构建、鼠标和真实 Chromium 触屏相机检查、四个视角的 28 次精确点选，以及手机、成功/失败和无 WebGL 的兼容显示检查。桌面与手机最终截图已更新；上述完整规则测试和八尺寸 UI 检查属于此前 UI 改造的验证记录。

独立合成场景覆盖 9 种设备造型（包含三种物资）、门柜开启、控制器修复、开关切换、危险状态、标记和未知回波。验证机器人转向、搬运伤员、选格及移除旧观察对象。连续切换 60 次状态后，GPU 记录始终为 3 个几何体和 11 张纹理，合成场景为 70 次绘制调用；浏览器运行错误为 0。测试展示只使用合成设备数据，不读取关卡隐藏实体。

修复缩放按钮仅修改相机参数、未重绘画面的问题：`zoomBy()` 显式请求渲染，不依赖 OrbitControls 对外部缩放赋值发出 change 事件。通过桌面鼠标、键盘 Enter 与 Chromium 触屏点击验证放大/缩小，检查实际图像变化、相机缩放值、0.65–3 的边界与复位；浏览器运行错误为 0，类型检查和构建通过。

## 适用范围

很矮的手机和横屏窗口允许纵向滚动，以维持可读地图和可达控件。当前验证覆盖本机 Chromium，实际手机 GPU、Safari 和 Firefox 的表现仍需对应设备验证。
